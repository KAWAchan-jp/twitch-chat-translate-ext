# fix/hint-bar-placement

## 目的

展開中に認識ヒント欄がパネル下部に表示される問題を直す。通常展開時はヘッダー直下、折りたたみ時は入力欄直上に表示する。

## 実装方針

- `hintBar` は1つだけ維持し、状態遷移時にDOM上の位置を移動する。
- 展開時は `#header` の直後へ置く。
- 折りたたみ時は `#inputArea` の直前へ置き、入力欄とフッターを下へ押し出す。
- 同一要素を移動するため、入力内容・イベントリスナー・`whisper_prompt` 保存処理を重複させない。

## 確認項目

- 展開中に💡を押すと、ヘッダー直下にヒント欄が表示される。
- 折りたたみ中に💡を押すと、入力欄直上にヒント欄が表示される。
- 開閉と折りたたみの切替後も、入力・保存・フォーカスが維持される。
